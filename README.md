# Ather Qureshi

Personal portfolio — Next.js, shadcn/ui, Vercel.

- Edit resume content in [`other/resume.ts`](./other/resume.ts)
- PDF is generated on demand at `/api/resume` (no static PDF required)
- Optional local export: `npm run generate:resume`
- Local: `npm run dev`
- Deploy: connect this repo to [Vercel](https://vercel.com)
